# 🩺 Breast Cancer Decision Support System (DSS)

A Machine Learning based Breast Cancer Decision Support System developed using Python, Flask, and Scikit-learn. The system predicts whether a tumor is Benign or Malignant based on 30 clinical input parameters.
## 🚀 Features

- 🧠 Breast Cancer Prediction using Machine Learning
- 📊 Real-time Prediction with Flask
- 📋 Clinical Data Input Form
- 📈 Confidence Score Prediction
- 🌐 Responsive Web Interface
- 🏥 Clinical Decision Support System
## 🛠️ Technologies Used

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML
- CSS
- Bootstrap
